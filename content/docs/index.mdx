Welcome to the SunShade Systems central documentation portal. This portal unifies system architecture and product guides across all applications.

## Ecosystem Architecture

SunShade builds focused applications on a shared platform foundation. Each product manages its own user experience while sharing core authentication and platform data boundaries.

### Platform Services

- **SunShade Hub**: Central identity provider and unified single sign-on across all applications.
- **SunShade DB Platform**: Central data layer enforcing multi-tenant isolation and shared database invariants.
- **SunShade Docs**: Central documentation engine and AI catalog generator for the entire ecosystem.

### Product Portfolio

- **Cozy**: Positivity-focused behavioral home and micro-space check-in app.
- **Patchwork**: Collaborative fabric planning and community workspace.
- **Votary**: Intentional ritual tracking and personal habit accountability.
- **Dart-Up**: Precision target practice and competitive tournament tracker.
- **SunShade Tracker**: Operational telemetry and audit log viewer.

## Living Binder Printing

You can print any page directly into your physical Living Binder. Use your browser print dialog (`Ctrl+P` or `Cmd+P`). The print layout automatically strips navigation bars and sidebars, expands content to full width, and prevents awkward page breaks inside tables and callout boxes.

## AI Agent Integration

AI coding agents use our root catalog at `/llms.txt`. Each application provides a scoped bundle at `/{project}/llms-full.txt` that merges application guides with shared architecture invariants.
